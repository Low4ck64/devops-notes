# git 
Второй день обучения новые команды в Gti
-Git add это означает что файл готов к комиту ".", "название файл" ты указываешь какой именно файл готов к комиту т.е. я указываю файл git add ".", это делается сохранение всей папки, а если я напишу "название моего файла" то после команды git commit будет сохранен именно этот файл
-git commit -m это команда работает как и обычнай коммит только она подписывает его уловно: git commit -m "конспект по воторому дню обучения" в гидхабе мой комит будет подписан именно так
-git commit записывает снимок этого файла в историю, как точку сохранения в игре
-git push это отправка сохранения в репозиторий
